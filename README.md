# Nexa-Restaurant-Newsletter India – Responsive HTML Email Templates

## Project Overview
This project contains two responsive HTML email templates developed for Nexa Restaurant India.

## Project Deliverables

1. **Kitchen Notes Email**
   - File: `kitchen.html`
   - Image: `kitchen.jpg`

2. **Dining Room Update Email**
   - File: `dinning.html`
   - Image: `dinning.jpg`

## Technologies Used
- HTML5
- CSS3
- Inline CSS
- Responsive design
- HTML tables for email layout

## Features
- Responsive email layouts
- Restaurant-themed design
- Food and dining images
- Mobile-friendly styling
- Email-compatible HTML structure

## Testing
Both templates were opened and tested in Google Chrome. The Kitchen Notes template was also tested in Gmail.
